# Legacy experimental source

This directory is the earlier auxiliary-token research snapshot. Its code and
paths are retained for compatibility with earlier experiments; it is not the
current manuscript's complete reproduction package.

Start with [`paper/`](../paper/) for the supplied four-register reconstruction
supplement and read the [release status](../paper/RELEASE_STATUS.md) for missing
inputs and validation limits. The [historical README](../docs/LEGACY_README.md)
documents the broader legacy experiments.
